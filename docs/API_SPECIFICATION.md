# QueueWise REST API Specification

**Version:** 1.0  
**Base URL:** `/api/v1`  
**Source of truth:** [PRD.md](PRD.md), [TRD.md](TRD.md), and [DATABASE_DESIGN.md](DATABASE_DESIGN.md)

## 1. API Conventions

Every endpoint below explicitly defines its HTTP method, URL, authentication requirement, required role, headers, path parameters, query parameters, request body, response body, HTTP status codes, validation errors, authorization errors, and possible business errors. Where an endpoint has no value for one of those fields, it is stated as `None`.

### Authentication

Protected endpoints require:

```http
Authorization: Bearer <short-lived-access-token>
Content-Type: application/json
Accept: application/json
X-Correlation-Id: optional-client-generated-id
```

`Content-Type` is required for requests with a body. `X-Correlation-Id` is echoed or generated by the server and is safe to share with support. JWTs contain user, organization, role, issue, and expiry claims. Authentication is stateless for access tokens.

### Common path and query rules

- `{id}` values are UUIDs unless explicitly described otherwise.
- Dates use ISO-8601 `YYYY-MM-DD`.
- Instants use ISO-8601 UTC timestamps.
- Pagination uses `page` zero-based and `size` from 1 to 100.
- List responses use `{ "items": [], "page": { ... } }` where pagination applies.
- Unknown query parameters are rejected where strict request validation is enabled.
- All resource lookups are organization-scoped; an unknown out-of-scope resource returns the same safe not-found response as a missing resource.

### Standard error response

```json
{
  "timestamp": "2026-09-17T10:15:30Z",
  "status": 400,
  "error": "VALIDATION_ERROR",
  "message": "One or more fields are invalid.",
  "path": "/api/v1/appointments",
  "correlationId": "b1e3c9f5-5f62-4c5e-bc8a-8c5bc0e6fb5a",
  "errors": [
    {
      "field": "scheduledStart",
      "code": "NOT_BOOKABLE",
      "message": "The selected slot is not available."
    }
  ]
}
```

The API never exposes stack traces, SQL, entity names, provider secrets, password details, or internal exception messages.

Standard error codes:

| HTTP | Error | Meaning |
|---:|---|---|
| 400 | `VALIDATION_ERROR` | Malformed or invalid input |
| 401 | `AUTHENTICATION_REQUIRED` / `INVALID_CREDENTIALS` | Missing or invalid authentication |
| 403 | `FORBIDDEN` | Authenticated but outside role or scope |
| 404 | `RESOURCE_NOT_FOUND` | Resource absent or outside scope |
| 409 | `CONFLICT` / `INVALID_STATE` / `CAPACITY_UNAVAILABLE` | Current state or uniqueness conflict |
| 422 | `BUSINESS_RULE_VIOLATION` | Valid shape but disallowed business operation |
| 429 | `RATE_LIMITED` | Too many requests |
| 500 | `INTERNAL_ERROR` | Unexpected server failure; use correlation ID |
| 503 | `DEPENDENCY_UNAVAILABLE` | Required dependency unavailable; queue state is not rolled back unnecessarily |

Validation errors describe malformed input, authorization errors describe missing role or resource scope, and business errors describe a valid request that cannot be performed because of current product state, capacity, timing, or lifecycle rules.

## 2. Authentication

### `POST /auth/register`

- **Authentication:** Public.
- **Role:** None; creates `CUSTOMER` by default.
- **Headers:** `Content-Type`, `Accept`, optional `X-Correlation-Id`.
- **Path/query:** None.
- **Request body:**

```json
{
  "organizationId": "uuid",
  "firstName": "Maya",
  "lastName": "Patel",
  "email": "maya@example.com",
  "phone": "+15551234567",
  "password": "strong-password"
}
```

- **Response:** `201 Created` with `{ "user": { "id", "firstName", "lastName", "email", "phone", "roles" }, "accessToken": "...", "expiresAt": "..." }`.
- **Errors:** `400` invalid fields; `409` contact already registered; `404` organization not found/inactive; `429` registration throttled.

### `POST /auth/login`

- **Authentication:** Public.
- **Role:** None.
- **Headers:** `Content-Type`, `Accept`.
- **Path/query:** None.
- **Request body:** `{ "organizationId": "uuid", "login": "email-or-phone", "password": "..." }`.
- **Response:** `200 OK` with access token, expiry, user summary, roles, and organization scope.
- **Errors:** `400` missing fields; `401` invalid credentials or inactive account; `429` login throttled.

### `POST /auth/logout`

- **Authentication:** Required.
- **Role:** Any authenticated role.
- **Headers:** Authorization, Accept, optional correlation ID.
- **Path/query/body:** None.
- **Response:** `204 No Content`.
- **Errors:** `401` invalid/expired token. Logout is idempotent from the client's perspective.

## 3. Users

### `GET /users/me`

- **Authentication:** Required; any role.
- **Headers:** Authorization, Accept.
- **Path/query/body:** None.
- **Response:** `200 OK` with user profile, roles, organization, assignments, and notification preferences summary.
- **Errors:** `401` unauthenticated; `404` account no longer available.

### `PATCH /users/me`

- **Authentication:** Required.
- **Role:** Any authenticated user for their own permitted profile fields.
- **Headers:** Authorization, Content-Type, Accept.
- **Path/query:** None.
- **Body:** Any of `firstName`, `lastName`, `phone`, or permitted preference fields.
- **Response:** `200 OK` with updated user DTO.
- **Errors:** `400` invalid format; `409` phone already used; `403` immutable/admin-only field attempted.

### `GET /users`

- **Authentication:** Required.
- **Role:** `ADMIN` or scoped `SUPERVISOR` where enabled.
- **Headers:** Authorization, Accept.
- **Query:** `status`, `role`, `search`, `page`, `size`.
- **Body/path:** None.
- **Response:** `200 OK` paginated user summaries without password or credential data.
- **Errors:** `400` invalid filters; `403` insufficient scope.

### `POST /users/staff`

- **Authentication:** Required.
- **Role:** `ADMIN`.
- **Headers:** Authorization, Content-Type, Accept.
- **Body:** `{ "firstName", "lastName", "email", "phone", "role": "STAFF|RECEPTIONIST|SUPERVISOR", "serviceIds": [], "counterIds": [] }`.
- **Response:** `201 Created` with staff DTO and assignments.
- **Errors:** `400` invalid role/fields; `403` not admin; `409` contact or assignment conflict.

### `PATCH /users/{id}/status`

- **Authentication:** Required.
- **Role:** `ADMIN`.
- **Path:** `id` user UUID.
- **Headers:** Authorization, Content-Type, Accept.
- **Body:** `{ "status": "ACTIVE|INACTIVE|LOCKED", "reason": "..." }`.
- **Response:** `200 OK` updated user status.
- **Errors:** `400` invalid status or missing reason; `404` user not found; `409` cannot deactivate the last active admin.

### `PUT /users/{id}/assignments`

- **Authentication:** Required.
- **Role:** `ADMIN`.
- **Path:** `id` staff UUID.
- **Headers:** Authorization, Content-Type, Accept.
- **Body:** `{ "serviceIds": ["uuid"], "counterIds": ["uuid"] }`.
- **Response:** `200 OK` assignment summary.
- **Errors:** `400` invalid IDs; `403` not admin; `404` staff/service/counter not found; `409` cross-organization assignment.

## 4. Services

### `GET /services`

- **Authentication:** Public or authenticated customer according to organization policy.
- **Role:** Any permitted viewer.
- **Headers:** Accept; optional Authorization.
- **Query:** `organizationId`, `status` (default `ACTIVE`), `date`, `page`, `size`.
- **Response:** `200 OK` paginated service summaries with description, duration, instructions, and bookability.
- **Errors:** `400` invalid date/pagination; `404` organization not found.

### `GET /services/{id}`

- **Authentication:** Public or authenticated according to policy.
- **Role:** Any permitted viewer.
- **Path:** service UUID.
- **Headers:** Accept; optional Authorization.
- **Response:** `200 OK` service detail including hours and booking rules; inactive details are admin-scoped.
- **Errors:** `404` not found or not visible.

### `POST /services`

- **Authentication:** Required.
- **Role:** `ADMIN`.
- **Headers:** Authorization, Content-Type, Accept.
- **Body:** `{ "name", "description", "instructions", "estimatedDurationSeconds", "bookingHorizonDays", "slotCapacity", "gracePeriodMinutes", "cancellationCutoffMinutes", "hours": [] }`.
- **Response:** `201 Created` service DTO and `Location` header.
- **Errors:** `400` field/rule validation; `403` not admin; `409` duplicate name.

### `PATCH /services/{id}`

- **Authentication:** Required.
- **Role:** `ADMIN`.
- **Path:** service UUID.
- **Headers:** Authorization, Content-Type, Accept.
- **Body:** Partial editable service configuration and optional `version` for optimistic concurrency.
- **Response:** `200 OK` updated service DTO.
- **Errors:** `400` invalid rules; `404` not found; `409` stale version or change conflicts with active bookings.

### `POST /services/{id}/deactivate`

- **Authentication:** Required.
- **Role:** `ADMIN`.
- **Path:** service UUID.
- **Headers:** Authorization, Content-Type, Accept.
- **Body:** `{ "reason": "..." }`.
- **Response:** `200 OK` service with `INACTIVE` status.
- **Errors:** `400` missing reason; `404` not found; `409` already inactive. Historical appointments remain.

## 5. Appointments

### `GET /appointments/availability`

- **Authentication:** Optional for public booking; required if customer identity is used for conflict checks.
- **Role:** Customer or authorized staff booking on behalf.
- **Headers:** Accept, optional Authorization.
- **Query:** required `serviceId`, `date`; optional `timezone`.
- **Response:** `200 OK` `{ "serviceId", "date", "timezone", "slots": [{ "start", "end", "remainingCapacity", "bookable" }] }`.
- **Errors:** `400` invalid date/time zone; `404` service not found; `422` service closed or outside booking horizon.

### `POST /appointments`

- **Authentication:** Required.
- **Role:** `CUSTOMER`, or `RECEPTIONIST`/`ADMIN` when booking on behalf is enabled.
- **Headers:** Authorization, Content-Type, Accept, optional idempotency key.
- **Body:** `{ "serviceId": "uuid", "customerId": "uuid", "scheduledStart": "2026-09-17T10:00:00Z", "scheduledEnd": "2026-09-17T10:30:00Z" }`; customer may omit `customerId` for self-booking.
- **Response:** `201 Created` appointment with token summary and confirmation code.
- **Errors:** `400` invalid interval; `403` booking on behalf not allowed; `404` service/customer missing; `409` duplicate/overlapping appointment or capacity unavailable; `422` closed, late, or outside horizon.

### `GET /appointments`

- **Authentication:** Required.
- **Role:** Customer sees own records; staff/admin see only configured scope.
- **Headers:** Authorization, Accept.
- **Query:** `status`, `from`, `to`, `serviceId`, `customerId` only for permitted staff, `page`, `size`.
- **Response:** `200 OK` paginated appointment DTOs with token status when present.
- **Errors:** `400` invalid filter; `403` out of scope.

### `GET /appointments/{id}`

- **Authentication:** Required.
- **Role:** Owner customer, assigned staff, supervisor, or admin.
- **Path:** appointment UUID.
- **Headers:** Authorization, Accept.
- **Response:** `200 OK` appointment detail, token reference, service instructions, and lifecycle timestamps.
- **Errors:** `404` missing/out of scope; `403` unauthorized scope.

### `POST /appointments/{id}/cancel`

- **Authentication:** Required.
- **Role:** Owning `CUSTOMER`, `RECEPTIONIST`, `SUPERVISOR`, or `ADMIN` according to policy.
- **Path:** appointment UUID.
- **Headers:** Authorization, Content-Type, Accept.
- **Body:** `{ "reason": "..." }`.
- **Response:** `200 OK` cancelled appointment and token status.
- **Errors:** `400` reason missing when required; `403` cannot cancel; `404` not found; `409` already terminal; `422` cancellation cutoff passed.

## 6. Tokens

### `POST /walk-ins`

- **Authentication:** Required.
- **Role:** `RECEPTIONIST`, `SUPERVISOR`, or `ADMIN`.
- **Headers:** Authorization, Content-Type, Accept, optional idempotency key.
- **Body:** `{ "customerId": "uuid", "serviceId": "uuid", "priority": "NORMAL|URGENT" }`.
- **Response:** `201 Created` token DTO with display code, queue, position, and estimated wait.
- **Errors:** `400` invalid priority/IDs; `403` role or urgent-priority permission denied; `404` customer/service missing; `409` no active compatible capacity or duplicate idempotency key; `422` service closed.

### `GET /tokens/{id}`

- **Authentication:** Required.
- **Role:** Owner customer, assigned staff, supervisor, receptionist scope, or admin.
- **Path:** token UUID.
- **Headers:** Authorization, Accept.
- **Response:** `200 OK` token detail with status, queue position when waiting, estimated wait, service, counter, and timestamps.
- **Errors:** `404` missing/out of scope; `403` unauthorized.

### `GET /tokens`

- **Authentication:** Required.
- **Role:** Customer own tokens; staff/admin scoped tokens.
- **Headers:** Authorization, Accept.
- **Query:** `status`, `serviceId`, `date`, `source`, `priority`, `page`, `size`.
- **Response:** `200 OK` paginated token summaries.
- **Errors:** `400` invalid filters; `403` scope violation.

### `POST /tokens/{id}/cancel`

- **Authentication:** Required.
- **Role:** Owner customer, receptionist, supervisor, or admin according to policy.
- **Path:** token UUID.
- **Headers:** Authorization, Content-Type, Accept.
- **Body:** `{ "reason": "..." }`.
- **Response:** `200 OK` token with `CANCELLED` status.
- **Errors:** `404` not found; `403` unauthorized; `409` token already called/in service/terminal; `422` policy forbids cancellation.

### `POST /tokens/{id}/start`

- **Authentication:** Required.
- **Role:** `STAFF`, `SUPERVISOR`, or audited admin override.
- **Path:** token UUID.
- **Headers:** Authorization, Content-Type, Accept.
- **Body:** `{ "counterId": "uuid" }`.
- **Response:** `200 OK` token with `IN_SERVICE` and start timestamp.
- **Errors:** `400` invalid counter; `403` staff not assigned; `404` not found; `409` wrong state, counter mismatch, or counter occupied.

### `POST /tokens/{id}/complete`

- **Authentication:** Required.
- **Role:** Staff assigned to the active counter, supervisor, or audited admin override.
- **Path:** token UUID.
- **Headers:** Authorization, Content-Type, Accept.
- **Body:** `{ "counterId": "uuid", "notes": "optional non-sensitive note" }`.
- **Response:** `200 OK` completed token with service duration.
- **Errors:** `403` unauthorized counter; `404` not found; `409` not `IN_SERVICE` or already completed; `400` invalid notes.

### `POST /tokens/{id}/skip`

- **Authentication:** Required.
- **Role:** Assigned staff, supervisor, or admin.
- **Path:** token UUID.
- **Headers:** Authorization, Content-Type, Accept.
- **Body:** `{ "counterId": "uuid", "reason": "CUSTOMER_ABSENT|CUSTOMER_REQUEST|OTHER" }`.
- **Response:** `200 OK` token with `SKIPPED` status and reason.
- **Errors:** `400` missing/invalid reason; `403` unauthorized; `404` not found; `409` invalid current state.

### `POST /tokens/{id}/no-show`

- **Authentication:** Required.
- **Role:** `STAFF`, `SUPERVISOR`, or `ADMIN` according to policy.
- **Path:** token UUID.
- **Headers:** Authorization, Content-Type, Accept.
- **Body:** `{ "reason": "CUSTOMER_ABSENT" }`.
- **Response:** `200 OK` token with `NO_SHOW` status.
- **Errors:** `403` unauthorized; `404` not found; `409` not called/overdue or already terminal.

### `GET /tokens/{id}/events`

- **Authentication:** Required.
- **Role:** Owner customer receives a safe subset; staff/admin receive scoped history.
- **Path/query:** token UUID; optional `page`, `size`.
- **Headers:** Authorization, Accept.
- **Response:** `200 OK` ordered lifecycle event list with actor display policy and timestamps.
- **Errors:** `400` invalid pagination; `404` not found; `403` out of scope.

## 7. Queues

### `GET /queues`

- **Authentication:** Required.
- **Role:** Customer for own queue summary; receptionist/staff/supervisor/admin for assigned scope.
- **Headers:** Authorization, Accept.
- **Query:** required `serviceId` and `date`; optional `counterId`, `includeCompleted`, `page`, `size`.
- **Response:** `200 OK` queue DTO with status, counts, waiting tokens, positions, estimates, compatible counters, and last update timestamp.
- **Errors:** `400` invalid date/IDs; `403` scope violation; `404` queue/service not found.

### `GET /queues/{id}/next`

- **Authentication:** Required.
- **Role:** Staff, supervisor, or admin in scope.
- **Path:** queue UUID.
- **Headers:** Authorization, Accept.
- **Response:** `200 OK` next eligible token preview, or `204 No Content` if none is eligible.
- **Errors:** `403` out of scope; `404` queue not found; `409` queue/counter state changed during preview.

## 8. Counters

### `GET /counters`

- **Authentication:** Required.
- **Role:** Staff sees assigned counters; supervisor/admin sees scoped counters.
- **Headers:** Authorization, Accept.
- **Query:** `status`, `serviceId`, `page`, `size`.
- **Response:** `200 OK` paginated counter DTOs with compatibility and current state.
- **Errors:** `400` invalid filters; `403` scope violation.

### `POST /counters`

- **Authentication:** Required.
- **Role:** `ADMIN`.
- **Headers:** Authorization, Content-Type, Accept.
- **Body:** `{ "name": "Counter 1", "locationLabel": "Main Hall", "serviceIds": ["uuid"] }`.
- **Response:** `201 Created` counter DTO and `Location` header.
- **Errors:** `400` invalid fields; `403` not admin; `404` service missing; `409` duplicate name or incompatible organization.

### `PATCH /counters/{id}`

- **Authentication:** Required.
- **Role:** `ADMIN`.
- **Path:** counter UUID.
- **Headers:** Authorization, Content-Type, Accept.
- **Body:** Partial name, location, status, or compatibility configuration plus optional `version`.
- **Response:** `200 OK` updated counter DTO.
- **Errors:** `400` invalid state/configuration; `404` not found; `409` stale version or active-work conflict.

### `PUT /counters/{id}/services`

- **Authentication:** Required.
- **Role:** `ADMIN`.
- **Path:** counter UUID.
- **Headers:** Authorization, Content-Type, Accept.
- **Body:** `{ "serviceIds": ["uuid"] }`.
- **Response:** `200 OK` compatibility list.
- **Errors:** `400` empty/invalid list where disallowed; `404` counter/service missing; `409` removing compatibility for active work.

### `POST /counters/{id}/select`

- **Authentication:** Required.
- **Role:** `STAFF` or `SUPERVISOR` assigned to the counter.
- **Path:** counter UUID.
- **Headers:** Authorization, Content-Type, Accept.
- **Body:** None.
- **Response:** `200 OK` counter session and counter state `IN_USE`.
- **Errors:** `403` staff not assigned; `404` not found; `409` counter inactive, paused, or already occupied.

### `POST /counters/{id}/release`

- **Authentication:** Required.
- **Role:** Current staff, supervisor, or admin.
- **Path:** counter UUID.
- **Headers:** Authorization, Content-Type, Accept.
- **Body:** `{ "reason": "END_SHIFT" }`.
- **Response:** `200 OK` counter state `AVAILABLE`.
- **Errors:** `403` not current staff; `404` not found; `409` active token prevents release.

### `POST /counters/{id}/pause`

- **Authentication:** Required.
- **Role:** Current staff, supervisor, or admin.
- **Path:** counter UUID.
- **Headers:** Authorization, Content-Type, Accept.
- **Body:** `{ "reason": "BREAK" }`.
- **Response:** `200 OK` counter state `PAUSED` and pause timestamp.
- **Errors:** `400` reason missing; `403` unauthorized; `404` not found; `409` cannot pause under current active-service policy.

### `POST /counters/{id}/resume`

- **Authentication:** Required.
- **Role:** Current staff, supervisor, or admin.
- **Path:** counter UUID.
- **Headers:** Authorization, Content-Type, Accept.
- **Body:** None.
- **Response:** `200 OK` counter state `AVAILABLE` or `IN_USE`.
- **Errors:** `403` unauthorized; `404` not found; `409` counter is inactive or not paused.

## 11. Audit

### `GET /audit-logs`

- **Authentication:** Required.
- **Role:** `ADMIN`; supervisors may receive a restricted operational subset if configured.
- **Headers:** Authorization, Accept.
- **Query:** `from`, `to`, `actorUserId`, `action`, `entityType`, `entityId`, `outcome`, `page`, `size`.

## 12. WebSocket Contract

REST is the source of truth; WebSocket is for updates. The client connects to `/ws` with a JWT, then subscribes only to authorized destinations:

- `/topic/organizations/{organizationId}/queues/{serviceId}`
- `/topic/counters/{counterId}`
- `/user/queue/token-updates`

Example message:

```json
{
  "eventType": "TOKEN_STATUS_CHANGED",
  "tokenId": "uuid",
  "queueId": "uuid",
  "status": "CALLED",
  "position": null,
  "estimatedWaitSeconds": 0,
  "version": 12,
  "occurredAt": "2026-09-17T10:15:30Z"
}
```

Clients must refetch REST state after reconnecting. A WebSocket message cannot authorize an operation or replace a REST command.

## 13. Cross-Cutting Validation and Authorization Rules

- IDs must be valid UUIDs and must belong to the current organization scope.
- Dates and times must be valid in the organization's configured time zone.
- Passwords are validated for minimum length and never echoed in an error.
- Service, counter, and staff assignments cannot cross organizations.
- Customers cannot change another customer's appointments or tokens.
- Staff cannot process a token through an incompatible or unassigned counter.
- Urgent priority requires the configured permission and creates an audit event.
- Start, complete, skip, no-show, cancel, pause, and resume commands validate current state inside a transaction.
- Repeated commands should be idempotent where safe; otherwise return `409 INVALID_STATE` without mutation.
- Error messages are safe, actionable, and never expose internal exception or database details.
